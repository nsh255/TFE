# TFE — Ascension (Unity)

Este repositorio contiene el proyecto del TFG y el videojuego **Ascension** (Unity).

## Ejecutar el juego (Windows)

- Ejecutable: `Ascension/Ascension/Build/Ascension.exe`
- Si al ejecutarlo falta algún archivo, asegúrate de mantener junto al `.exe` las carpetas `Ascension_Data/`, `MonoBleedingEdge/` y el resto del contenido de `Build/`.

## Abrir el proyecto en Unity (Editor)

**Requisitos**
- Unity: `6000.2.7f2` (Unity 6)

**Pasos**
1. Abre **Unity Hub**.
2. "Add" / "Añadir" proyecto y selecciona la carpeta: `Ascension/Ascension/`.
3. Abre el proyecto con Unity `6000.2.7f2`.
4. En el editor, abre una escena desde `Assets/Scenes/` (por ejemplo, la del menú principal) y pulsa **Play**.

## Build del juego (opcional)

1. En Unity: **File → Build Settings**.
2. Selecciona la plataforma (Windows) y pulsa **Build**.

---

Nota: La carpeta `Ascension/Ascension/Build/` está incluida a propósito para poder ejecutar el juego sin necesidad de compilarlo.
